# lawofmessiah_translations

This directory is intended to be managed as a Git submodule.

Purpose:
- Store translations for content sourced from `https://github.com/walkasjesus/LawofMessiah`.
- Keep these translations separate from project static/template translations.

Language scope:
- Dutch (`nl`) only.

Expected layout:
- `locale/nl/LC_MESSAGES/django.po`
